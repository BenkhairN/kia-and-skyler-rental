# Images

The easiest way to add vehicle photos is from the admin dashboard:
Admin > Vehicles > Edit (pencil icon) > Photos. Upload or drag up to 6 photos;
the first one is the cover shown on the website. Uploaded photos are resized and
saved in the browser together with the rest of the site data.

The home page photo is uploaded separately in Admin > Settings > Home page photo.

- `public/images/cars/` - vehicle photos
- `public/images/hero.jpg` - optional hero background for the home page

Until a photo exists, the UI renders a styled placeholder automatically.
